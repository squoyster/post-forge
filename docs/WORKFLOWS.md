# DKMC Post-Forge Workflows

## Workflow 1 — Live Replay Distribution

Input: a newly ingested Mahatma live recording.

Outputs:

- Facebook Page replay post
- YouTube replay package
- 3 to 7 short clip proposals
- 2 quote/reflection card proposals
- 1 next-live reminder draft

Steps:

1. Confirm video-rag ingestion completed.
2. Generate summary from transcript chunks.
3. Create replay post.
4. Mine high-quality clip candidates.
5. Generate visual quote/reflection cards.
6. Present everything to human reviewer.
7. Queue approved posts across 7 to 14 days.

## Workflow 2 — Short Clip

1. Query video-rag for topic/date intent.
2. Select candidate clip.
3. Require reviewer approval.
4. Allow start/end adjustment.
5. Generate ASS captions.
6. Render intro card.
7. Cut/normalize clip.
8. Burn captions.
9. Add outro with CTA.
10. Export MP4 and caption text.

## Workflow 3 — Text/Image Reflection

1. Query video-rag for useful teaching chunk.
2. Extract a grounded quote.
3. Generate short reflection.
4. Render 1080x1350 image card.
5. Generate Facebook caption.
6. Present to reviewer.
7. Queue approved post.

## Workflow 4 — Growth Campaign

Goal: reach Page follower/subscriber thresholds without making the page look desperate.

Rules:

- Soft follow CTA in roughly 1 of 3 posts.
- YouTube subscribe CTA in replay and Shorts packages.
- No visible follower-count begging except occasional operational note.
- Useful teaching remains the main value proposition.
