# DKMC Post-Forge Template Assets

Initial DKMC Facebook/YouTube visual content system for `post-forge`.

Design goal: make the DKMC page feel like a clean satsang companion: useful short teachings, live/replay reminders, reflection cards, and clips mined from the existing satsang archive.

Primary outputs:

- Facebook Page image posts
- Facebook Reels / video posts
- YouTube Shorts
- Full replay announcement posts
- Live reminder posts

The visual system is named `Satsang Dawn`.
